# LIVE Mock Login Details

Use any of the following accounts on the `/login` page.

Selecting **Use a demo account** opens the account sheet. Choosing an account only fills its email and password; it does not sign in automatically. Press **Sign in** after selecting the account.

| Workspace | Email | Password | Best page to test |
|---|---|---|---|
| Requester with active response | `requester@live.co.za` | `LiveUser123!` | Live map, request tracking, notifications and history |
| Requester without an active request | `newrequester@live.co.za` | `LiveNewUser123!` | Automatic location and the three-step request flow |
| Dispatcher | `dispatcher@live.co.za` | `LiveDispatch123!` | Queue, incident management, responder assignment and status updates |
| Responder | `responder@live.co.za` | `LiveRespond123!` | Mission map and progress actions |
| Administrator | `admin@live.co.za` | `LiveAdmin123!` | Users, organisations, audit logs and prototype settings |
| Auditor | `auditor@live.co.za` | `LiveAudit123!` | Read-only incident and audit review |

The authentication and database are simulated in the browser. These are not production credentials.
